# M5Stack CoreS3 👻「三合一」极客超级形态使用指南

> **答案是：1 + 2 + 3 不仅能一起用，而且固件从底层架构就是为了三合一同时并发运行而设计的！**  
> 一台巴掌大的 M5Stack CoreS3，插上一根 Type-C，同时兼具：
> 1. 🛡️ **物理级免驱防封 HID 键鼠 + 触屏物理急停**
> 2. 🤖 **赛博 AI 代码搭子（动态眨眼/情绪反馈/声音音效）**
> 3. 🎙️ **手持无线 AI 对讲机（按住说话 -> 自动转文字 -> 自动敲入电脑当前窗口）**

## ⚡ 1 + 2 + 3 三合一真实联动工作流

### 第一步：连电脑 & 启动对讲机服务
1. 用 USB-C 数据线将 CoreS3 连接至电脑。
2. 电脑端打开终端，运行后台对讲机守护进程：
   ```bash
   python scripts/walkie_talkie.py
   ```
   *控制台将打印：`✨ 成功握手 M5Stack CoreS3 对讲机设备 [COMx]！`*

---

### 第二步：三合一全场景实操演示

#### 体验 3：手持对讲机（随拿随说，自动打字）
1. 拿起桌上的 CoreS3，光标停留在你的编程软件中（VS Code / Antigravity / Cursor / Claude）。
2. **大拇指长按屏幕中间的【🎙️ 按住说】**，屏幕瞬间切换为呼吸红圈与实时音频波形跳动。
3. 对着 CoreS3 说话，例如：*“帮我把这个函数重构一下，加一下单测”*。
4. **松开手指**：CoreS3 播放清脆完成音效，电脑输入框瞬间自动敲入文字并回车！

#### 体验 2：赛博代码搭子（实时情绪陪伴）
- 平常状态下，屏幕上的赛博大眼睛会自然眨动（待命中）；
- 当你或 AI 脚本执行繁重任务时，终端敲：
  ```bash
  python scripts/buddy.py thinking "正在思考重构方案..."
  ```
  CoreS3 眼睛瞬间变金橙色，眼珠左右扫视，状态栏显示当前思考内容；
- 任务成功时：
  ```bash
  python scripts/buddy.py done "重构完毕！单测全绿！"
  ```
  CoreS3 眼睛变成翠绿笑眼 `^ ^` 并欢快提示！

#### 体验 1：物理硬件防封与宏键 / 急停
- **一键免键盘确认**：当 AI 终端询问 `Do you want to proceed? [y/n]` 时，你不需要碰键盘，**直接单手点一下 CoreS3 屏幕左下角的【APPROVE (Y)】**，CoreS3 的 ESP32-S3 硬件底层直接通过 USB 物理下发 `y + 回车`！
- **一键否决**：点右下角【REJECT (N)】，直接下发 `n + 回车`。
- **物理急停 (E-STOP)**：GhostDesk 自动化接管桌面操作微信/Excel时，一旦遇到意外弹窗，**手指按住屏幕红框**，单片机在硬件物理底层瞬间强行释放所有按键、切断会话并告警！

## 🛠️ 怎么把固件刷进你的 CoreS3？

### 极速方式 A：网页一键刷（Chrome / Edge 浏览器）
1. 用 Chrome 打开本地文件：`firmware/m5stack_cores3/web_flasher.html`；
2. 点击连接你的 CoreS3 串口，一键烧录！

### 极速方式 B：Arduino IDE 2.x
1. 安装 `M5Unified` 库；
2. 打开 `firmware/m5stack_cores3/m5stack_cores3.ino`；
3. 开发板选择 `M5Stack-CoreS3`，设置：
   - **USB Mode**: `Hardware CDC and JTAG`
   - **USB CDC On Boot**: `Enabled`
4. 点击 Upload 烧录，拔插一次即大功告成！
