# Pico 到货、烧录与 0.5 固件输入法测试

测试电脑要求：**Windows 11 x64（Intel / AMD 64 位）**。这是当前客户端支持与验收范围；Mac 版待 Windows 实机验收通过并修复问题后再开发。

适用硬件为 **Raspberry Pi Pico 1（RP2040，Pico H 可）** 和 Micro-USB 数据线。不适用于 Pico W、Pico 2、Leonardo。FlowDesk 0.5 使用协议 4；旧固件不可混用。

本说明用于 FlowDesk 0.7 软件配合 0.5 协议 4 固件的测试；0.7 没有更改 Pico 固件或协议。已有匹配 0.5 UF2 的板无需再次烧录。匹配固件 Pico 是启动电脑操作、持续回复和审核后逐键填入的必需硬件，自动与人工草稿模式均不例外；未连接时只能查看管理和烧录说明。本地模拟结果见对应验收记录，Windows 11 x64 实体板与真实输入法仍待用户按以下步骤验收。

## 烧录

1. 解压软件包，找到 `FlowDesk-Pico-RP2040.uf2` 与同目录校验文件。
2. 按住 Pico 板载 BOOTSEL 后插入数据线，出现 `RPI-RP2` 盘。
3. 将 UF2 拖入该盘，等待板子重启。
4. 打开 FlowDesk 的“USB 硬件”，使用“一键识别”：唯一 FlowDesk 匹配设备只读连接，不会启动 HID；多个匹配时手动选择对应 COM 端口并连接。

本版不需要外接按钮、杜邦线或焊接。连接后不会自行操作；只在软件点击开始后执行，停止或断线会停止。

固件 SHA-256：`722545026E55CC8A3C89ED02C7E598CF4B40A8620915C9D3E2435D863F32EC8D`。

## 自建窗口先测

1. 在“USB 硬件”的自建测试输入区点击输入框。
2. 点击“测试输入”，确认只在这个测试框出现 `FlowDesk`；再点击“测试移动”，确认光标只发生一次小幅移动。
3. 使用“停止设备会话”和“断开”确认设备可被软件停止。

## 再测逐键中文

1. 先在 FlowDesk 内置虚构聊天窗口验证，不使用真实账号。
2. 选择 Pico USB HID，配置能读图片的视觉模型，并选择自动回复。
3. 在目标窗口启用全拼；验证 Shift 切中英、数字选候选、PageDown 翻页。
4. 从空白输入框开始，最大化窗口，确保候选页完整显示在窗口内。
5. 发起虚构回复后，检查逐键拼音、候选数字选择和发送结果。Gemini 模式使用同一 Gemini API Key 的模型做候选识别，不另设普通视觉模型；此逐键输入路径不使用剪贴板、粘贴或 Enter。

首批适配目标为微软、微信、搜狗、百度输入法；自建 fixture 的四种样式只是模拟外观，不等于品牌或实体板验收。emoji、多行、双拼、五笔不在本轮范围。候选识别不确定、窗口失焦、取消或未提交拼音时，停止并人工清理草稿后再继续。

没有 `RPI-RP2` 或 COM 时，先检查数据线是否支持数据传输；仅在固件版本不匹配时重新烧录匹配的 0.5 UF2。
