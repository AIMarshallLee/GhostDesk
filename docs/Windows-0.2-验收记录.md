# FlowDesk 0.2 Windows 持续回复验收记录

本轮增加真实 Windows 窗口的持续监听、多会话回复、手动复制、区域校准和持久运行记录。原先模拟器内的自动回复及单次 UI-TARS 任务继续保留。

## 已有证据

- 五分钟实际计时：302 秒、三会话、13 批、39 次独立视觉确认；模型服务实际收到 752 个来自自建窗口的 PNG 附件。结束时暂停，没有继续发送。观察到的主进程 JS 堆约 8–10 MB。证据：`artifacts/replies-soak.log`。
- 主进程 engine + 视觉 surface + OpenAI 兼容 HTTP 调用 + 虚构桌面窗闭环：连续第二次消息、多会话隔离、人工模式不发送、发送故障不重试、暂停与重启不补发。证据：`desktop/replies-smoke.ts`。
- Windows PrintWindow/SendInput 曾在自建窗完成中文输入、切换会话与两次发送。随后改为复用原生辅助进程，编译、通信与取消测试已通过；当前包的实际键鼠复验尚待自建窗保持前台。非选定窗口获得前台时，输入守卫取消后续动作；未截图或操作真实账号。
- 回归 83/83 通过，覆盖持久化损坏、并发启动、启动中停止、生成中接管、发送中暂停、同文新消息、草稿占用、回复视觉确认、接口校验、窗口身份和进程取消。证据：`artifacts/tests-replies.log`。旧粘贴功能的进程身份检查另外通过无原生输入的模拟验证。
- 打包和独立 ZIP 解压验证均通过：原界面 IPC、UI-TARS SDK 闭环、持续回复闭环及 203 个运行文件/许可证字节核对。独立解压包内版本确认为 0.2.0。最终包为 `release/FlowDesk-win32-x64.zip`，163,218,364 字节；SHA-256 为 `349d358a9d3ab94146a1f5d51d69829a26e3a5d752bbcb55ed058408afe650f9`。证据：`artifacts/portable-verification.json`。

## 商业验收边界

上述模型响应来自本机测试服务，不证明客户模型的视觉准确率，也不等于目标平台服务器送达回执。当前没有真实客户 API 与指定业务软件版本的验收结果，没有一天/一周的连续运行证据，也没有代码签名。

客户使用前应在独立测试账号和确定的软件版本、显示缩放下验收；开发过程中禁止使用用户的真实微信。不能宣传“任意模型/任意软件通用”“24 小时零故障”“防封号保证”。

软件复用 Electron、React、UI-TARS SDK；新增的部分是客户会话检查点、队列、知识上下文、发送前后复核和恢复逻辑。无需 USB、Node.js 或 Python。
