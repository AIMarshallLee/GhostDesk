# Windows 0.7 验收记录

日期：2026-09-15。范围：FlowDesk 0.7 的 Gemini 原生持续多会话回复、普通视觉模型兼容路径、学习候选审核、显式附件导入和 FlowDesk Pico 自动发现。

## 实现边界

- 桌面持续回复支持 Gemini 原生或普通 OpenAI 兼容视觉模型；可监听多个已配置会话。设备发现只识别匹配 FlowDesk PnP 元数据，不因发现设备而自动开始任务。
- 知识与 SOP 学习只产生待审核候选。候选可由本地整理生成，或在明确授权后交给配置的模型整理；只有人工审核后才写入并启用。
- 附件必须由用户明确导入，支持 PNG、JPEG、WebP、MP3、WAV、PDF、CSV、TXT。不会自动收集聊天窗口中的附件。
- Pico 固件保持 0.5.0、协议 4；当前支持与验收范围为 Windows 11 x64。真实账号、真实模型、实体 Pico、真实输入法和目标应用不属于本轮本地验证。
