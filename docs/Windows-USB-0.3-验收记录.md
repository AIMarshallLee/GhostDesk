# FlowDesk 0.3.0 Windows + USB 开发验证

本轮沿用 Electron、React、UI-TARS SDK、Pico SDK 和 TinyUSB，接通现有 Windows 软件与 Pico 1 RP2040 固件。协议 2 支持实体按钮准备、会话心跳、鼠标和快捷键，中文通过客户端临时剪贴板配合 USB Ctrl+V。自动回复与人工复制回复保留。

## 已完成的模拟闭环

- Node 回归：100/100 通过，记录在 `artifacts/tests-usb.log`。
- USB 端到端模拟：316 条命令、260 次相对移动、31 次点击、5 次粘贴；三会话自动回复、人工草稿、发送不确定时不重试、暂停与重启恢复。最终 marker 在所有断言和清理完成后输出。
- 五分钟实际计时模拟：302 秒、13 批、3 会话、39 次回复和画面确认；747 次真实渲染窗口 PNG 请求；同一 USB 模拟会话、149 次心跳、3266 条设备命令。暂停后没有发送。
- 两项测试都使用虚拟 COM 传输、虚拟剪贴板、本机 HTTP 模型替身及 FlowDesk 自建虚构聊天窗口。没有调用真实模型、接触真实剪贴板、打开真实 COM、注入系统键鼠或操作账号。
- 构建后的工作台检查包含 USB 页面、持续回复 USB 选择器、默认未连接状态和受限 IPC。
