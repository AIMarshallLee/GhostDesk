# FlowDesk 0.4.0：软件启停，免外接按钮

本轮按用户要求简化现有 Windows + Pico USB HID 方案。开发板只需 Pico 1 / Pico H（RP2040，非 W）和 Micro-USB 数据线，不再需要外接 GPIO15 按钮、杜邦线、焊接或按键准备步骤。板载 BOOTSEL 只在烧录时使用，板载 LED 显示会话运行状态。

## 行为变化

- 连接、刷新或查询设备只进入待机；软件中的明确启动操作才开始会话。
- 自动回复、人工复制回复与 Computer Use 沿用现有软件；开始、暂停、停止均由 Windows 控制。单次设备自检完成后停止，可以直接再次点击自检。
- 断开串口时释放 DTR，设备收到断开信号后清理动作和会话；物理拔出、挂起及心跳超时也会清理。断线后不自动恢复，不回退为 Windows 软件输入。
- 连接丢失的检测有传播和超时时间，已交付主机的输入不能撤回。主机卡死而连接未关闭时由 10 秒心跳租期兜底。不能把这一机制描述为任何故障下都瞬时零输入。
- 软件、固件均为 0.4.0，握手协议为 3。旧 0.3 固件仍要求外接按钮，需要重新烧录；新软件明确拒绝旧协议。

## 本地验证范围

开发测试只使用 FlowDesk 自建虚构聊天窗口、虚拟 USB/剪贴板、包含生产 main.c 的 C fake HAL 和本机 HTTP 模型替身。不打开真实 COM，不调用真实视觉模型，不读取真实剪贴板，不向操作系统注入键鼠，不操作用户微信或其他账号。
