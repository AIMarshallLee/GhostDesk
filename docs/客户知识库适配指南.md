# FlowDesk 客户知识库适配指南（演示模板）

> 用途：为单个客户准备 3–5 个工作日的知识库适配候选和 5–7 个工作日的受控试用检查。本文和同目录 CSV 只含纯虚构的产品 A/B 示例，演示内容不可原样用于客户。适配排期是目标，不代表已完成或已验收的能力。

## 范围与边界

- 每个客户使用独立的 Windows 用户或独立部署数据目录（当前没有应用内客户切换器）和独立知识库，禁止把不同客户的资料、候选答案、回放记录或导出文件混在一起。
- 可接收并人工确认的资料类型：`xlsx`、`docx`、文本型 `PDF`、`CSV`、`JSON`、`TXT`、`MD`，以及经客户明确授权和整理的角色聊天记录。
- 扫描 PDF 需要先做 OCR，再由客户确认 OCR 文本；不直接承诺自动识别扫描件，也不把 OCR 草稿当作事实。
- 当前适配只生成候选、预览、去重、回放和审核记录；没有客户真实账号操作、自动外发或自动启用的授权。
- 年费 3000–5000 元是拟定报价区间，不是已验证的盈利或客户成交事实。是否包含 1 台 Win11 设备、业务范围和知识条目额度，需由商务另行明确；模型 API 费用与硬件费用单列。

## 资料收集

在客户独立工作区建立资料清单，记录文件名、来源角色、更新时间、格式、是否包含个人信息、是否需要 OCR，以及客户联系人。先收齐业务范围和允许回答的角色，再开始整理。

建议让客户提供：产品/服务说明、价格与有效期、服务边界、售后规则、常见问题、销售和客服话术、社区规范、招聘或内容场景的口径。聊天记录只收取客户明确指定的对话和角色，不自动抓取附件或账号内容。

## 脱敏和确认事实

1. 删除或替换姓名、手机号、邮箱、地址、订单号、账号标识、密钥、内部链接和其他不必要的个人信息。
2. 将每条口径拆成“确认事实、待确认、推测/示例”三类；只有客户确认的事实才可进入可启用知识。
3. 对价格、服务范围、有效期、交付方式、退款/赔付、优惠和承诺逐项找事实来源与确认人。缺少来源时保留待确认状态，不自行补写。
4. 对虚构产品 A/B 示例加演示标识，禁止把示例价格、功能或服务边界当成客户承诺。

## 统一导入预览去重

Word、文本 PDF 和 TXT/MD 可直接生成原文候选；结构化 FAQ 表格按软件包同目录的 `knowledge-template.csv`（源码位于 public/）填写固定列：标题、问题、标准答案、相似问法、标签、场景。相似问法和标签内部用 `|` 分隔；场景仅使用 `service`、`sales`、`community`、`recruitment`、`content`、`all`。

导入前预览原文、解析结果和字段缺失项。软件按规范化问题或标题、正文和场景做精确指纹去重；语义相近项仍须人工整理。重复条目合并前由适配人员保留来源与客户确认人。对于冲突口径，不覆盖旧内容，单独标记冲突并回到客户确认。

## 审核启用

由客户指定的业务负责人逐条审核候选。另行维护的客户确认记录至少包括：通过、需修改、拒绝、待确认，以及审核人和日期。只有通过的条目才可进入启用集合；未审核、来源不明、含敏感信息或包含未经确认承诺的条目保持停用。

## 20–50 个问题回放

使用软件包同目录的 `knowledge-evaluation-template.csv`（源码位于 public/） 扩展为 20–50 个问题，覆盖正常问法、相似问法、边界问法、跨场景问法、过期/冲突口径和应无命中的问题。记录实际命中标题、回答是否符合已确认事实、是否越过服务边界、是否需要人工接管。评测 CSV 中“预期留空”的问题必须保持无命中预期，不得为了通过而补知识。

回放结果只证明本机候选数据的检索与审核流程经过检查，不证明真实客户效果、模型质量、销量、转化、盈利或客户采纳。

## 受控试用（5–7 天检查单）

| 天数 | 检查项 | 产出/通过条件 |
|---|---|---|
| 第 1 天 | 建立客户独立工作区；登记资料、角色、业务范围、设备和联系人；确认数据处理边界 | 清单完整；无跨客户文件；客户确认资料范围 |
| 第 2 天 | 完成脱敏；抽样核对价格、服务边界、有效期和禁止承诺；扫描 PDF 先完成 OCR 草稿 | 脱敏记录可追溯；OCR 草稿未被当作事实；待确认项已列出 |
| 第 3 天 | 统一导入预览；检查格式映射、缺失字段、相似问法和标签分隔；执行初次去重 | 预览可读；冲突和重复均有记录；未发生静默覆盖 |
| 第 4 天 | 业务负责人审核并启用通过项；保留需修改、拒绝和待确认项 | 每条启用项有审核人/日期；未审核项未启用 |
| 第 5 天 | 回放 20–50 个问题；至少包含 2 个应无命中问题；记录命中、越界、人工接管和修订 | 回放记录完整；应无命中项没有被强行命中；问题有责任人 |
| 第 6 天（可选） | 在客户指定的低风险范围内进行受控试用；每日抽样复核回答和人工接管 | 仅使用已审核知识；异常可停用；无自动外发或真实账号操作 |
| 第 7 天（可选） | 汇总问题、修订候选和残留风险；客户核对最终范围与后续报价 | 形成试用记录和待办；客户知道尚未证明的事项 |

若第 2–5 天任一关键检查未通过，延长适配或停止试用，不把 3–5 天目标当作交付承诺。受控试用的外部发送、真实账号操作、部署、付款和客户正式验收均需另行取得明确授权，并在记录中单列。

## 客户签确认

签确认前向客户展示：资料清单、脱敏与事实确认记录、导入预览与去重记录、审核状态、20–50 问题回放、受控试用异常和未解决风险。签字内容应明确知识范围、设备/Win11 约定、条目额度、模型 API 与硬件费用、服务期限、人工审核责任和停用方式。

客户签确认只证明双方对本次资料范围和试用记录达成确认，不等同于销量、转化、盈利、模型效果或长期采用已经验证。
