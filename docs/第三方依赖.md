# 第三方依赖与实现边界

## 应用依赖

所有 JavaScript 包通过 npm 安装并由 `package-lock.json` 锁定精确版本，开发包不作为商业服务承诺。

| 组件 | 用途 | 许可证 |
| --- | --- | --- |
| React / React DOM | Web 与 Electron 渲染 UI | MIT |
| Vite | 本地开发及静态构建 | MIT |
| Electron | Windows 应用运行时 | MIT；附带 Chromium 等第三方声明 |
| Lucide | 界面图标 | ISC |
| DM Sans、Noto Sans SC | 本地打包字体，无 Google Fonts 运行时请求 | SIL Open Font License |
| TypeScript、esbuild、tsx | 编译与测试 | 各包随附许可证 |
| Electron Packager | 生成 Windows 便携包 | BSD-2-Clause |

Electron 运行时许可证随分发包保留；React、React DOM、Lucide 和字体许可证同时复制到客户端内的 `desktop-build/licenses/`。开发依赖的声明保留在对应 npm 包中。

## USB 固件

采用 Raspberry Pi Pico SDK 与 TinyUSB。具体版本、来源、工具链与上游许可证记录在 `firmware/README.md` 及固件依赖记录中。

开发固件使用的示例 USB VID/PID 仅用于开发验证；不构成量产 VID/PID 授权。该产品没有采购实物、设计量产 PCB、申请标识或硬件认证。
