👻 GhostDesk M5Stack CoreS3 网页秒级烧录

无需安装任何 Python、Arduino IDE 或 VS Code 编译环境。直接使用 Chrome 或 Edge 浏览器即可向你的 M5Stack CoreS3 写入固件。

  1. 使用 Type-C 数据线将 M5Stack CoreS3 顶部 USB 口连接至电脑。
  2. 点击下方 CONNECT / 安装固件 按钮。
  3. 在浏览器弹出的设备列表中选择包含 ESP32-S3 或 USB JTAG/serial debug unit 的串口。
  4. 确认烧录，等待进度条走完（约 30 秒），设备重启即告完成！
⚠️ 提示：浏览器安全策略禁止在本地 file:// 协议下访问 WebSerial 串口接口。
请使用轻量服务器打开本页面：
npx serve . 或 python -m http.server 8000
然后在 Chrome / Edge 中访问 http://localhost:8000/web_flasher.html 即可正常烧录！
⚠️ 您的浏览器不支持 WebSerial，请使用 Google Chrome 或 Microsoft Edge 访问本页面。
